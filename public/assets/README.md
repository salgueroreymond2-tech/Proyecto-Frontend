# Assets

Estructura publica de recursos estaticos de KAS.

- `logos/brand`: logos de marca y variantes de identidad.
- `logos/teams`: escudos o logos oficiales de equipos.
- `images/sports`: imagenes por deporte usadas en cards, heroes y carruseles.
- `images/generated`: imagenes generadas o fondos auxiliares.

Las rutas usadas por React se centralizan en `src/config/assets.ts`.
